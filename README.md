正在收集工作区信息# STM32F407自动行驶小车控制系统

## 项目概述
本项目基于STM32F407系列MCU设计了一套小车自动行驶控制系统，旨在实现路径跟踪和精准停车功能。小车能够按照预设路径在指定场地中完成多项任务，包括直线行驶、循迹、精准转向等。

## 硬件配置
- 主控：STM32F407VETx微控制器
- 传感器：
  - JY901陀螺仪模块（方向角度感知）
  - 灰度传感器（黑线检测）
  - 编码器（距离测量）
- 显示：2.0英寸LCD (320x240)
- 存储：SD卡接口
- 驱动：电机驱动模块

## 软件架构
本项目使用基于状态机的设计模式，主要功能模块包括：

1. **任务控制模块**：实现了四个主要任务，每个任务有各自的状态机控制流程
2. **运动控制模块**：提供直线行驶、转向、循迹等基本运动功能
3. **传感器处理模块**：处理陀螺仪数据和灰度传感器数据
4. **菜单系统**：基于轻量级菜单框架cot_menu，实现人机交互界面
5. **调试系统**：通过串口输出调试信息，方便开发调试

## 主要功能
- **任务1**：从A点出发，沿直线行驶至B点后停车，全程不超过15秒
- **任务2**：从A点出发，沿直线行驶至B点，旋转180度后沿原路返回至A点
- **任务3**：A→C→B→D→A路径控制，包含直线行驶和黑线循迹功能
- **任务4**：更复杂的路径规划与执行,执行任务三4次

## 使用方法

### 编译与烧录
项目使用MDK-ARM进行开发，可通过以下步骤编译并烧录：
1. 使用Keil MDK打开`MDK-ARM/Downloads.uvprojx`项目文件
2. 配置编译选项（如优化级别等）
3. 编译项目并烧录到STM32F407开发板

### 操作说明
1. 系统启动后，通过LCD菜单界面可以选择不同任务
2. 每个任务执行过程中，系统会通过LED指示当前状态
3. 任务执行完成后，系统会给出声光提示

## 开发注意事项
- 陀螺仪初始化需要一定的稳定时间，任务开始前会等待传感器数据稳定
- 转向角度计算需考虑±180度范围内的角度规范化
- 各任务参数可在`car_config.h`中调整，便于优化性能

## 目录结构
```

├── control/         - 控制算法实现
│   ├── CONTROL/     - 小车主控制逻辑
│   ├── LineTracking/ - 循迹算法
│   └── MPU6050/     - 姿态传感器相关
├── Drivers/         - 硬件驱动
├── Hardware/        - 硬件接口
│   ├── ENCODER/     - 编码器接口
│   ├── LineDetect/  - 线检测模块
│   ├── IIC/         - I2C接口
│   └── JY901/       - 陀螺仪接口
├── MDK-ARM/         - Keil项目文件
└── Middlewares/     - 中间件
    ├── my_menu/     - 菜单系统
    └── USMART/      - 调试工具
```
